# Arkn.SourceGen

Source generator que elimina o boilerplate das fábricas de `Error`.

```bash
dotnet add package Arkn.SourceGen
```

> `Arkn.SourceGen` é uma dependência apenas de desenvolvimento e não é incluído no assembly de saída.

## Uso

```csharp
using Arkn.SourceGen;

[ArknErrors]
public static partial class UserErrors
{
    [ArknErrorCode("NotFound", "User was not found")]
    public static partial Error NotFound(string? detail = null);

    [ArknErrorCode("Validation", "Email address is not valid")]
    public static partial Error InvalidEmail(string? detail = null);

    [ArknErrorCode("Conflict", "A user with this email already exists")]
    public static partial Error EmailConflict(string? detail = null);
}
```

O gerador produz:

```csharp
// <auto-generated by Arkn.SourceGen />
public static partial class UserErrors
{
    public static partial Error NotFound(string? detail = null) =>
        Error.NotFound("UserErrors.NotFound", detail ?? "User was not found");

    public static partial Error InvalidEmail(string? detail = null) =>
        Error.Validation("UserErrors.InvalidEmail", detail ?? "Email address is not valid");

    public static partial Error EmailConflict(string? detail = null) =>
        Error.Conflict("UserErrors.EmailConflict", detail ?? "A user with this email already exists");
}
```

Os códigos de erro seguem a **ARK002** automaticamente: `NomeDaClasse.NomeDoMétodo`.
